# Jiajie Mei — academic website

This repository contains the public GitHub Pages site. The website uses plain HTML, CSS, and JavaScript. The `notes/` directory holds standalone HTML research notes.

The current CV is deliberately excluded while it is being updated. Mathematical typesetting in the helicity note loads MathJax from jsDelivr.

To add a note, place a complete `.html` file in `notes/` and update `notes/catalog.js` to include its title, summary, and tags.

Published at https://jiajiemei-hep.github.io/ using GitHub Pages from the `main` branch root.
